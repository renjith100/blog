---
title: A security center for Claude Enterprise
source: Anthropic
date: 2026-11-05
category: Claude Enterprise
---
Claude Enterprise admins get a security center in beta. It compares an organization's settings with what Anthropic recommends and can be exported as a report for auditors. Inference hooks, which check prompts and tool calls with an outside security tool before they run, are now generally available. Some other admin and access controls also arrived, a few of them in beta.
