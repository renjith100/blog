---
title: Cursor's cloud agents now deploy apps
source: Cursor
date: 2026-11-05
category: Cursor
---
Describe a web app and a Cursor cloud agent builds it, adds a Postgres database and Cursor SSO login when needed, and puts it on its own address to share with your team. Before anything goes live, Cursor runs security checks, and you still have to publish it yourself. It's on all paid plans that have cloud agents turned on.

[Cursor changelog](https://cursor.com/changelog/build-live-apps)
