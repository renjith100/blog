---
title: Talk to Cursor agents in a voice call
source: Cursor
date: 2026-11-06
category: Cursor
---
You can now talk to Cursor agents in a realtime voice call while they work, in the Agents Window, the IDE, on the web and in Cursor for iOS. The voice runs on xAI's Grok Voice, but the agent keeps using the model you picked. It's separate from dictation, and with Privacy Mode on, no data is kept.

[Cursor changelog](https://cursor.com/changelog/voice-chat)
