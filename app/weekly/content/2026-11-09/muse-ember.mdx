Muse Ember is a small, cheap model for the high-volume work agents repeat all day, like calling tools in sequence and making small code fixes. It costs $0.10 per million input tokens and $0.50 per million output, has a 1M-token context window and takes text, images, audio and video. Artificial Analysis scores it level with Claude Haiku 5.5 at about a third of the cost per task, though Haiku still does better on one coding benchmark. It's available in the Meta Model API.
